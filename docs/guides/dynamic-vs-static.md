# Dynamic vs. static QR codes

## Dynamic codes

A dynamic code encodes a short Lynqr address (`lynqr.app/q/AbC1234`). When someone scans it, Lynqr records the scan and sends them to the code's **current** destination.

- **Change the destination after printing.** Update a website, swap the menu PDF or edit a contact card; the printed code keeps working.
- **Measure every scan** by time, location, device and more.
- **Pause, expire or password-protect** the destination at any time.
- **Smaller, cleaner patterns**, because the encoded address is short.

Website, document, app-store and contact-card codes can be dynamic. Documents and app-store codes are always dynamic.

## Static codes

A static code contains the content itself: Wi-Fi credentials, a phone number, an email draft or text.

- **Works offline**, with nothing between the scanner and the content.
- **Can't be changed or tracked** once printed. Editing the content changes the pattern, so existing prints keep the old content.

Use static codes for Wi-Fi, phone, SMS, email and plain text, and wherever a code must work without an internet connection.
