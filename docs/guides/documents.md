# Hosting documents

Upload a PDF, image, presentation, spreadsheet or text file (up to 15 MB) on the **Documents** page. Lynqr creates a dynamic QR code for it automatically.

## Replace without reprinting
Click **Upload a new version** on any document. Every QR code and link pointing at it serves the new file immediately, and the version number goes up. This is ideal for daily specials, quarterly reports and event agendas.

## Sharing
- Each document has a stable link (`lynqr.app/d/…`) that always opens the latest version.
- Create extra QR codes for the same document, for example one per table or location, to compare scans.

## Safety
Files are stored privately with random, unguessable names. Web pages and scripts are always downloaded rather than opened, so an uploaded file can never run code on your behalf.
